Name: Free Touchscreen Test
Domain: freetouchscreentest.com

Create a web app for testing touchscreen functionality. The app should cover the following:

Touch Detection

Detect and display whether the device supports touch input
Show the number of simultaneous touch points supported (maxTouchPoints)

Multi-Touch Tracking

Track and visualize all active touch points simultaneously
Display each touch point as a labeled circle with its identifier, X/Y coordinates, and touch pressure/force if available

Gesture Recognition

Detect and identify common gestures: tap, double-tap, long press, swipe (all 4 directions), pinch-in, pinch-out, and rotation
Show the last recognized gesture with a timestamp

Draw / Finger Paint Test

A canvas area where the user can draw freely with one or multiple fingers
Include a clear button and stroke color/size options

Tap Accuracy Grid

A grid of target zones the user must tap in sequence to test tap precision
Report hit/miss results and average accuracy score

Response Latency Test

Measure and display the time between a visual prompt appearing and the user tapping it
Run multiple rounds and show average, min, and max latency

Scroll & Pan Test

A scrollable/pannable content area to verify smooth touch scrolling behavior
Indicate scroll direction and velocity

Touch Event Log

A live log panel showing raw touch events (touchstart, touchmove, touchend, touchcancel) with timestamps and coordinates
